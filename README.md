# Employee Turnover Prediction

## About the Project
This project predicts whether an employee will stay in a company or leave using Machine Learning.

The project uses Logistic Regression to predict employee turnover and compares three models:
- Baseline Logistic Regression
- Lasso Logistic Regression (L1)
- Ridge Logistic Regression (L2)

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Import the required libraries.
2. Load and explore the dataset.
3. Prepare the data for Machine Learning.
4. Split the dataset into training and testing data.
5. Train Baseline, Lasso, and Ridge Logistic Regression models.
6. Predict employee turnover.
7. Evaluate and compare model performance.

## Model Results

| Model | Training Accuracy | Testing Accuracy | Precision |
|---|---:|---:|---:|
| Baseline Logistic Regression | 86.39% | 85.93% | 87.18% |
| Lasso Logistic Regression | 86.67% | 87.04% | 88.14% |
| Ridge Logistic Regression | 86.39% | 85.93% | 87.18% |

## Best Model
Lasso Logistic Regression achieved the highest testing accuracy of **87.04%** and precision of **88.14%** among the three evaluated models.

## Conclusion
This project helped me understand Logistic Regression, L1 and L2 regularization, employee turnover prediction, and model evaluation.

Lasso Logistic Regression performed best among the three models based on the reported testing results.
